# مواصفات الشاشات الرائدة (Wireframe Spec) — بيت الكرم

مواصفة تفصيلية لكل شاشة من الـ 18 شاشة الرائدة قبل تحويلها لتصميم UI نهائي على الـ Canvas. كل شاشة تشمل: الغرض، التخطيط، القرارات التصميمية، الحالة الفارغة، وحالة الخطأ.

> **تصحيح:** الإصدار الأول من هذا المستند افترض خطأً أن **اتجاه المنتج الافتراضي RTL/عربي** وكتب كل الأمثلة التخطيطية بمنطق يمين-ليسار. الصحيح: **الإنجليزية هي اللغة الأساسية للمنتج (LTR)، والعربية خيار ثانوي عبر مبدّل لغة فقط.** التخطيطات الفعلية المُنفَّذة على الكانفس (`04-Design-System.md` والـ Artifact الخاص بالشاشات) تعتمد LTR كأساس — زر الرجوع يسار الشاشة، الشريط الجانبي للوحة التحكم يسار الشاشة، ترتيب التبويبات يبدأ من اليسار. الأمثلة التخطيطية النصية أدناه (مكتوبة سابقاً بمنطق RTL) توضيحية للتركيب العام للشاشة فقط (أماكن العناصر النسبية لبعضها) — اعتمد الكانفس الفعلي كمرجع للاتجاه الصحيح، لا هذه الرسوم النصية.

## قسم أ) تطبيق العملاء — Viewport: 390×844 (iPhone قياسي)

### 1. Splash Screen
```
┌─────────────────────────────────┐
│                                   │
│                                   │
│         [شعار بيت الكرم]           │  ← الشعار الأحمر يتوسط خلفية بيضاء نظيفة
│        بيت الكرم بالخط الكاليجرافي   │
│                                   │
│                                   │
│      [مؤشر تحميل بسيط أسفل]        │
└─────────────────────────────────┘
```
**الغرض:** أول انطباع بصري — يجب أن يشعر المستخدم فوراً بالهوية (الأحمر + الخط العربي الكاليجرافي) دون أي عنصر آخر يشتت.
**قرار UX:** مدة أقصاها 1.5 ثانية، لا شاشة تحميل طويلة، تحميل البيانات الأساسية يحدث في الخلفية أثناء عرض الشعار.
**حالة الخطأ:** فشل الاتصال بالسيرفر → الانتقال المباشر لشاشة "لا يوجد اتصال" بدل التجمّد على الشعار.

### 2. الرئيسية (Home)
```
┌─────────────────────────────────┐
│ [الموقع: فرع المهندسين ▾]    [🔔] │ ← Header: الموقع يمين (RTL)، الإشعارات يسار
├─────────────────────────────────┤
│  ┌───────────────────────────┐  │
│  │   بانر العروض (Carousel)    │  │ ← full-bleed، صورة طبق حقيقي + عرض نصي
│  └───────────────────────────┘  │
│  [🔍  ابحث عن طبقك المفضل...]    │
│  ─────────────────────────────  │
│  الفئات:  (تمرير أفقي من اليمين) │
│  [مشاوي] [مقبلات] [مشروبات] [حلويات]│
│  ─────────────────────────────  │
│  الأكثر طلباً                    │
│  [كارت صنف] [كارت صنف] [كارت صنف]→│ ← تمرير أفقي
│  ─────────────────────────────  │
│  🔁 اطلب نفس طلبك السابق         │
│  [كارت طلب سابق + زر "اطلب تاني"] │
├─────────────────────────────────┤
│ [الرئيسية][المنيو][طلباتي][الولاء][حسابي] │ ← Bottom Tab: أول تبويب يمين في RTL
└─────────────────────────────────┘
```
**قرار UX:** الفرع/الموقع الحالي دائماً ظاهر أعلى الشاشة وقابل للتغيير بضغطة (يمنع أكبر مصدر إحباط في تطبيقات التوصيل: الطلب من فرع خاطئ).
**الحالة الفارغة:** مستخدم جديد بدون طلبات سابقة → قسم "اطلب نفس طلبك" يُستبدل بقسم "جرّب الأكثر شعبية هذا الأسبوع".
**RTL:** الـ Bottom Tab Bar بترتيب معكوس بالكامل (الرئيسية أقصى اليمين)؛ اتجاه التمرير الأفقي للكاروسيل والفئات من اليمين لليسار.

### 3. اختيار/تحديد الفرع (Branch Selector)
```
┌─────────────────────────────────┐
│ [<] اختر الفرع                   │ ← سهم الرجوع يمين الشاشة (RTL)
├─────────────────────────────────┤
│ [خريطة مصغّرة تفاعلية]            │
├─────────────────────────────────┤
│ 📍 فرع المهندسين — 1.2 كم         │
│    مفتوح حتى 1:00 ص  [اختيار]    │
├─────────────────────────────────┤
│ 📍 فرع مدينة نصر — 3.5 كم         │
│    مفتوح حتى 12:00 م [اختيار]    │
├─────────────────────────────────┤
│ 📍 فرع الشيخ زايد — 8 كم [مغلق الآن]│ ← معطّل بصرياً، رمادي
└─────────────────────────────────┘
```
**قرار UX:** الفروع المغلقة تظهر بترتيبها الجغرافي لكن بمظهر معطّل بدل إخفائها — شفافية كاملة مع العميل.
**حالة الخطأ:** تعذر تحديد الموقع الجغرافي → البحث اليدوي بالاسم/المنطقة يظهر تلقائياً كبديل أساسي وليس ثانوي.

```
┌─────────────────────────────────┐

│         [خريطة كبيرة]             │
```

**قرار UX:** Bottom Sheet قابل للسحب لأعلى ليعرض كل الفروع كقائمة كاملة مع الحفاظ على الخريطة ظاهرة جزئياً.

### 5. المنيو الرئيسي (Menu)
```
┌─────────────────────────────────┐
│ المنيو            [🔍]           │
├─────────────────────────────────┤
│ [مشاوي*][مقبلات][سلطات][حلويات]→ │ ← Sticky Tabs، التبويب النشط بخط أحمر سفلي
├─────────────────────────────────┤
│ ┌───────┐  كباب حلبي              │
│ │ صورة  │  وصف مختصر للطبق         │
│ │       │  85 ج.م          [+]    │ ← زر إضافة سريعة دائري
│ └───────┘                         │
│ ┌───────┐  شيش طاووق              │
│ │ صورة  │  ...                    │
│ └───────┘  95 ج.م          [+]    │
└─────────────────────────────────┘
```
**قرار UX:** زر "+" يفتح Bottom Sheet مصغّر لإضافة سريعة (بدون إضافات) للأصناف البسيطة، بينما الأصناف ذات الخيارات المتعددة (حجم/إضافات إجبارية) تفتح شاشة التفاصيل الكاملة مباشرة.
**الحالة الفارغة:** فئة بدون أصناف متاحة حالياً → رسالة ودّية "هذا القسم هيرجع قريب، جرّب أطباقنا التانية" + رابط لأكثر الفئات طلباً.

### 6. تفاصيل الصنف (Item Detail)
```
┌─────────────────────────────────┐
│ [صورة كبيرة full-bleed للطبق]     │
│ [<]                        [♡]   │ ← رجوع يمين، مفضلة يسار
├─────────────────────────────────┤
│ كباب حلبي                85 ج.م  │
│ وصف تفصيلي للطبق ومكوناته...      │
│ ─────────────────────────────   │
│ الحجم:  ( ) عادي  (•) وسط  ( ) كبير│
│ إضافات: [✓] أرز  [ ] بطاطس +15ج.م │
│ ملاحظات: [صندوق نص حر]            │
├─────────────────────────────────┤
│ [–] 1 [+]      [أضف للسلة — 85 ج.م]│ ← ثابت أسفل الشاشة

```
**قرار UX:** السعر داخل زر "أضف للسلة" يتحدّث لحظياً مع تغيير الحجم/الكمية — شفافية سعرية كاملة قبل الضغط.
**حالة الخطأ:** نفاد إضافة معينة أثناء الاختيار → تعطيلها فورياً برسالة "غير متوفر الآن" بدل السماح بإضافتها ثم الفشل عند الدفع.

```
├─────────────────────────────────┤
│ كباب حلبي × 1           85 ج.م   │
│   حجم وسط، بدون بصل    [تعديل][🗑]│
```

**قرار UX:** تعديل صنف من السلة يعيد فتح شاشة تفاصيل الصنف بنفس الاختيارات السابقة محمّلة مسبقاً، وليس شاشة فارغة.

```
┌─────────────────────────────────┐
```

```
├─────────────────────────────────┤
│ ●──────●──────●──────○           │ ← Stepper أفقي (RTL: يبدأ من اليمين)
```

**الغرض:** الشاشة الأكثر إعادة فتحاً في كامل التطبيق — يجب أن تبعث الطمأنينة فوراً (خريطة حية + وقت واضح) وليس مجرد نص حالة.
**قرار UX:** لحالة "استلام من الفرع"، تُستبدل الخريطة بعدّاد تنازلي كبير لوقت الجاهزية بدل خريطة لا معنى لها.

## قواعد عامة مشتركة (كل الشاشات)

| الحالة | القاعدة |
|---|---|
| **حالة التحميل** | Skeleton screens بنفس تخطيط المحتوى الحقيقي (لا دوّار تحميل مجرد) |
| **حالة الخطأ الشبكي** | رسالة ودّية بالعامية المصرية + زر "إعادة المحاولة" — لا رسائل تقنية |
| **الحالة الفارغة** | رسم خطي (line-art) بسيط بروح النظام الزخرفي + نص تحفيزي + إجراء واضح |
| **الاتجاه** | الأساس LTR (سهم الرجوع يسار الشاشة، إلخ) — عند تفعيل العربية من الإعدادات فقط تُعكس كل الأيقونات ذات الاتجاه تلقائياً؛ الأرقام دائماً Western numerals بغض النظر عن اللغة |

# القائمة الكاملة — بيت الكرم (Full Menu Content)
### مصدر الحقيقة الوحيد لكل صنف يظهر في التطبيق ولوحة التحكم ودليل توليد الصور

هذه القائمة مبنية على مطبخين حقيقيين متكاملين — **السوري (الشامي/الحلبي)** و**المصري** — بما يعكس هوية بيت الكرم كبراند يجمع بين الأصالتين. كل صنف هنا سيُستخدم حرفياً في: شاشات المنيو، تفاصيل الصنف، السلة، محرر الصنف بلوحة التحكم، **ودليل توليد الصور** (`05-AI-Image-Generation-Brief.md`).

**رمز الصنف (SKU):** بادئة الفئة + رقم تسلسلي — يُستخدم كمُعرِّف ثابت عبر كل الوثائق والصور المولَّدة.

## كيفية الاستخدام

1. **شاشات المنيو والتفاصيل والسلة** — كل صنف هنا جاهز للاستخدام المباشر بنفس الاسم AR/EN والوصف والسعر، بدون الحاجة لأي محتوى إضافي.
2. **محرر الصنف بلوحة التحكم** — رمز الـ SKU يُستخدم كمُعرِّف داخلي مرجعي عند ربط كل صنف بصورته المولَّدة.
3. **دليل توليد الصور** (`05-AI-Image-Generation-Brief.md`) — تم توسيعه بالكامل ليغطي كل الـ 52 صنفاً هنا بنفس رموز SKU، بالإضافة لكل الأصول البصرية الأخرى التي يحتاجها المنتج.
